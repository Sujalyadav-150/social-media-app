# Social Media App

A simple frontend Social Media App inspired by the project shown in the reference video.

## Features

- Create a post using an image URL
- Add post description
- Display multiple posts
- Add comments to posts
- Comments are displayed as Anonymous
- Simple responsive UI

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- DOM Manipulation
- Browser events

## How to Run

Open `index.html` directly in a browser, or use VS Code Live Server.

No Node.js, Express, MongoDB, or backend is required for this version.
